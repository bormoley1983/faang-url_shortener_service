URL Shortener Service — это микросервис, который позволяет пользователям брать свои длинные реферальные ссылки и сокращать до очень маленьких. Это может быть полезно для тех, кто хочет поделиться ссылкой в социальных сетях, где длинные ссылки могут выглядеть непривлекательно и быть неудобными для использования. 

Основной функцией сервиса является сокращение URL-адресов, однако он также обладет функциональностью кэширования, многопоточности, работой с базой данных Postgres и Redis, REST-интерфейсом и планировщиком переиспользования ресурсов.

Более того, для оптимизации работы микросервиса добавлен локальный кэш прямо в памяти в потокобезопасной структуре данных, что значительно повышает эффективность работы.
